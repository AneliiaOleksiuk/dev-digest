# DevDigest

Local-first AI pull-request review. Course starter template: import a PR, run
an agent review on it, end to end. Later course lessons add features back —
see [README.md](README.md#what-you-build-in-the-course).

**Before starting work:** read [INSIGHTS.md](INSIGHTS.md) — treat its
entries as high-confidence guidance unless this file says otherwise.

**Stack:** Node ≥22, pnpm ≥10, Docker (Postgres/pgvector only — API and web run
on the host via `pnpm dev`).

## Packages (no workspace — separate `package.json`/lockfile each)

| Folder | Package | What | Port |
|---|---|---|---|
| `server/` | `@devdigest/api` | Fastify API + Drizzle/Postgres | 3001 |
| `client/` | `@devdigest/web` | Next.js 15 web app | 3000 |
| `reviewer-core/` | `@devdigest/reviewer-core` | diff → prompt → LLM → findings | — |
| `e2e/` | `@devdigest/e2e` | deterministic browser e2e | — |
| `mcp/` | `@devdigest/mcp` | stdio MCP server (review tools) + pre-push CLI (`devdigest review`) | — |

Cross-package sharing goes through **tsconfig path aliases**, not npm/workspace
deps — see each package's AGENTS.md.

## Cross-cutting conventions

- **Not a monorepo.** No workspace tooling; each package installs and runs
  independently. `./scripts/dev.sh` orchestrates local dev.
- **`@devdigest/shared` (Zod contracts) is manually copied**, not imported, into
  both `server/src/vendor/shared` and `client/src/vendor/shared` — no sync
  script exists. Edit one, mirror the other by hand.
- **Secrets never live in git or the database.** They're in
  `~/.devdigest/secrets.json` (mode `0600`), with `process.env` as a fallback.
- **Migrations are NOT applied on server boot** — always run
  `cd server && pnpm db:migrate` manually after pulling changes.
- **Cross-tool agent personas live in `agents/<name>.md`** (canonical) and
  are manually mirrored into `.claude/agents/`, `.codex/agents/`, and
  `.cursor/agents/` — same manual-mirror convention as `@devdigest/shared`,
  no sync script. See [agents/README.md](agents/README.md) for the full
  persona set and handoff chain.

## Cross-cutting gotchas

- `reviewer-core/` is the only package on **npm** (`package-lock.json`); every
  other package is **pnpm**. Don't "fix" that lockfile.
- `GITHUB_TOKEN` is canonical; `GITHUB_PAT` is accepted as a silent fallback.

## Do-not-touch

- `*/src/vendor/**` — hand-mirrored, not generated by tooling.
- `*/src/db/migrations/**` — generated by `drizzle-kit`, regenerate via
  `pnpm db:generate`, never hand-edit.
